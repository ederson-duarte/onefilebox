# One File Box

One File Box é um framework/ambiente JavaScript para desenvolvimento de sistemas web baseado em um único arquivo (`index.html`).

O objetivo é permitir a criação de aplicações completas que possam ser executadas localmente com uma estrutura mínima de arquivos e, quando necessário, utilizar o IndexedDB como banco de dados local.

## Plugins

O One File Box possui plugins que podem adicionar funcionalidades e ferramentas ao desenvolvimento de aplicações.

Alguns plugins podem ser disponibilizados separadamente como produtos comerciais.
